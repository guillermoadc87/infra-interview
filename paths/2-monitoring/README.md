# Path 2: Monitoring & Observability

## Overview

The application runs but there is zero visibility into its health, performance, or behavior. Your task is to assess the current observability gaps and implement a monitoring stack that would give confidence to operate this system in production.

## Your Mission

Identify what observability is missing from the current setup and implement a solution covering metrics collection, visualization, and alerting. You may modify the application code as needed.

## Requirements

### Must Have

- Identify and document the observability gaps in the current system
- Metrics collection with application instrumentation
- Visualization dashboards showing system health and performance
- Alerting for critical conditions with appropriate thresholds
- Documentation of your observability strategy and how to use it

### Bonus

We're interested in seeing depth of thinking about production observability. What would you add to build real confidence in this system's reliability?

## Evaluation

We evaluate metric selection, dashboard design, alert quality and actionability, implementation quality, production readiness, and documentation.

## Submission

Document your work in `SOLUTION.md`: what you changed, why, trade-offs you considered, and what you'd do with more time.
