# Path 4: CI/CD & GitOps

## Overview

The current deployment process is completely manual with no automation, testing, or deployment validation. Your task is to assess the deployment workflow and implement a modern CI/CD pipeline that enables safe, reliable, and auditable deployments.

## Your Mission

Design and implement an automated deployment pipeline. The result should be something you'd trust to deploy to production, with appropriate safety nets and controls.

## Requirements

### Must Have

- Identify and document the problems with the current deployment process
- Automated build and test pipeline
- Declarative deployment mechanism
- Deployment safety: health validation and rollback capability
- Documentation of the deployment workflow

### Bonus

We're interested in seeing how you think about deployment security and access patterns at scale. What concerns would you raise for a production deployment pipeline?

## Evaluation

We evaluate pipeline design, deployment safety, automation quality, production readiness, and how you think about the broader deployment lifecycle.

## Submission

Document your work in `SOLUTION.md`: what you built, why, trade-offs you considered, and what you'd do with more time.
