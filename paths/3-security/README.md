# Path 3: Security & Compliance

## Overview

The current setup has multiple security vulnerabilities and doesn't follow security best practices. Your task is to perform a security audit, identify the issues, and harden the infrastructure with appropriate controls.

## Your Mission

Audit the current deployment for security issues and implement defense-in-depth controls. The result should demonstrate a meaningful improvement in security posture that would be appropriate for a production environment handling sensitive data.

## Requirements

### Must Have

- Comprehensive security audit documenting all identified vulnerabilities
- Remediation of critical security issues
- Defense-in-depth: multiple layers of security controls
- Balance between security and operability
- Threat model documentation

### Bonus

We're interested in seeing how deeply you think about security. What would you consider the gold standard for securing a system like this?

## Evaluation

We evaluate security posture improvement, defense-in-depth thinking, least privilege application, production readiness, operational impact, and threat modeling.

## Submission

Document your work in `SOLUTION.md`: what you found, what you fixed, your threat model, trade-offs you considered, and what you'd do with more time.
